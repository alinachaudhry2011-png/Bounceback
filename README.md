# Bounceback

An asteroid is falling toward Earth, and you have to bounce it back into space!

## How to play
Tap or click to place shield pads (they fade after 3 seconds).
Bounce the asteroid off the pads to send it back up.
Chain bounces to build a combo multiplier (up to x5).
Grab stars for points. Avoid the red space mines.
Earth has one planetary shield that saves you once. It recharges every 10 points.
If the asteroid hits Earth again, Earth is destroyed.
Pick EASY, NORMAL, or HARD on the start screen. Your best score is saved.

## Built with
Plain HTML, CSS, and JavaScript (canvas). No libraries.
